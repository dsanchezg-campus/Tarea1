Este proyecto ha sido creado para practicar control de versiones con Git. 
Incluye una página principal con un mensaje introductorio, una tabla de horarios y un formulario de contacto

## Instalación

Este proyecto no requiere instalar dependencias ni servidores externos, ya que está desarrollado únicamente con HTML. Para obtener una copia local:

#### **1.** Clona el repositorio en tu equipo local:
```bash
git clone https://github.com/dsanchezg-campus/Tarea1.git
```
#### **2.** Accede al directorio del proyecto:
```bash
cd Tarea1
```
#### **3.** Ejecuta `index.html` 
Puedes abrir el archivo `index.html` haciendo doble clic sobre él desde tu explorador de archivos, o ejecutarlo desde la terminal según tu sistema operativo:
- **Windows:**
  ```bash
  start index.html
  ```
- **Linux:**
  ```bash
  xdg-open index.html
  ```

## Mejoras

### Tabla con horarios
- Incluye una tabla con los horarios de clase, incluye el descanso y el profesor de cada clase.
- Se ha utilizado `<thead>` y `<tbody>` para organizar la tabla semanticamente.
 
### Formulario de contacto
- Al final se incluye un formulario de contacto, la información de contacto necesaria es el **nombre y correo**, el número de telefono es opcional.
